# Current Focus
## Rail Compass
Rail Compass is a full-stack railway recommendation platform that recommends the **best** train instead of simply the fastest one.

Recommendations are generated using multiple factors including:
- Journey Duration
- Budget
- Comfort
- Historical Reliability
- Daytime Travel

### Built With
React • Node.js • Express.js • MongoDB
